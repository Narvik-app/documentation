# Démarrage rapide utilisateur

Votre compte est accessible depuis le menu de profil (en haut à droite) > `Profil`.
Vous y retrouvez votre adhésion au club, vos présences et la sécurité de votre compte (mot de passe, clés d'accès).

## Se connecter

Deux méthodes de connexion sont disponibles :
- **email et mot de passe**
- **clé d'accès** : connexion sans mot de passe ni email

## Clés d'accès

Une clé d'accès (*passkey*) remplace le mot de passe.

Vous vous connectez en déverrouillant votre appareil, avec votre empreinte digitale, la reconnaissance faciale ou le code de l'appareil.

- **Plus simple** : rien à retenir ni à saisir, pas même votre email.
- **Plus sûre** : une clé d'accès ne fonctionne que sur Narvik, elle ne peut pas être volée par un faux site (hameçonnage).  
  Narvik ne conserve aucun secret.  
  La clé reste sur votre appareil ou dans votre gestionnaire de mots de passe.

La clé d'accès est enregistrée par votre téléphone, votre ordinateur ou votre gestionnaire de mots de passe
(Google, Apple, Microsoft, Bitwarden, Enpass, ...), qui peut la synchroniser entre vos appareils.

### Ajouter une clé d'accès
1. Connectez-vous avec votre email et votre mot de passe.
2. Ouvrez la page `Mon compte`, bloc `Clés d'accès`, puis cliquez sur `Ajouter`.
3. Donnez-lui un nom si vous le souhaitez (par exemple « Téléphone »), puis cliquez sur `Créer la clé d'accès`.
4. Validez avec votre appareil (empreinte, visage ou code).

Vous pouvez ajouter plusieurs clés d'accès, par exemple une par appareil.

### Se connecter avec une clé d'accès
Sur la page de connexion :
- cliquez dans le champ email : vos clés d'accès sont proposées dans les suggestions, choisissez la vôtre ;
- ou cliquez sur `Se connecter avec une clé d'accès`.

Validez ensuite avec votre appareil : vous êtes connecté.

::: tip
Le bouton n'apparaît que si votre navigateur prend en charge les clés d'accès.
Votre mot de passe reste utilisable à tout moment.
:::

### Renommer ou supprimer une clé d'accès
Dans le bloc `Clés d'accès`, la date d'ajout et de dernière utilisation de chaque clé est affichée.
Utilisez le crayon pour la renommer, la corbeille pour la supprimer.

::: warning
Supprimer une clé d'accès dans Narvik ne la retire pas de votre appareil : pensez à la supprimer aussi
de votre gestionnaire de mots de passe.
:::
