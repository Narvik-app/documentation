# Installation manuelle
1. Télécharger le code source depuis la [page Github](https://github.com/Narvik-app/backend)
2. Copier et configurer le `.env.example` en `.env`
3. `composer install`

## Installation des consommateurs
Nous utilisons Symfony Messenger afin d'effectuer les traitements de façon asynchrone (envoi des emails, imports, exports), ainsi que Symfony Scheduler pour les tâches récurrentes (nettoyage des données, remise à zéro mensuelle du compteur d'emails).

Deux consommateurs doivent tourner en permanence :

```shell
# Traitements asynchrones
bin/console messenger:consume async_high async_medium async_low --time-limit=3600

# Tâches récurrentes, une seule instance
bin/console messenger:consume scheduler_default --time-limit=3600
```

Il est cependant conseillé de les faire tourner en tâche de fond. Aucun cron n'est nécessaire.

Le paramètre `--time-limit=3600` arrête le consommateur au bout d'une heure afin de libérer la mémoire.\
Pour que ces commandes se relancent automatiquement il faudra donc utiliser un superviseur avec comme [Supervisor](https://symfony.com/doc/current/messenger.html#messenger-supervisor) ou [systemd](https://symfony.com/doc/current/messenger.html#systemd-configuration)

https://symfony.com/doc/current/messenger.html#deploying-to-production

## Mise à jour

Pour effectuer les mises à jour, il faut :

1. Stopper les consommateurs
2. Récupérer la dernière version du code sur Github
3. `bin/console doctrine:migrations:migrate`
4. `bin/console install:default-settings`
5. Démarrer le serveur et les consommateurs
